# STK Annotation Update

This project provides scripts and workflows for updating kinase specificity annotations, focusing on the STK and PTK kinome. It leverages the KRSA platform and the latest kinome data resources.

## Resources

- **KRSA**: [Kinome Random Sampling Analyzer](https://github.com/CogDisResLab/KRSA)
- **reKRSA**: [reKRSA: reproducible KRSA](https://github.com/CogDisResLab/reKRSA)
- **STK Kinome Atlas Paper**: [A Kinome Atlas for Serine/Threonine Kinases](https://pubmed.ncbi.nlm.nih.gov/35012345/)
- **PTK Kinome Atlas Paper**: [A Kinome Atlas for Protein Tyrosine Kinases](https://pubmed.ncbi.nlm.nih.gov/36098765/)

## Overview

- Scripts for downloading, processing, and annotating kinase specificity data
- Integration with the latest GraphQL API for kinase library queries
- Output files for downstream analysis and visualization

For questions or contributions, please refer to the linked repositories above.
